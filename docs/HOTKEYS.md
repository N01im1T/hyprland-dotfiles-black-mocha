# Hotkeys

This checked-in page describes the mechanism, not a second source of definitions. The authoritative list is `config/keybinds.toml`; `dotctl apply` generates `~/.config/black-mocha/generated/HOTKEYS.md`, Hyprland bindings, and UI JSON from it.

The default essentials are Super+Return (terminal), Super+E (files), Super+Space (launcher), Super+Q (Kando), Super+A (control center), Super+/ (help), Super+L (lock), Super+C (clipboard), Super+. (emoji picker), Super+N (text editor), Super+Shift+W (Writer), Super+Shift+X (Calc), Super+V (AmneziaVPN), Super+Shift+T (Tor Browser), and Super+P (wallpaper).
